# Registration Evaluation Summary (Rigid + Affine)

This document summarizes the current validation of the atlas‑based registration
pipeline in the **gsoc-predict-cac-prototype** branch. All results are computed
on **synthetic NCCT demo data** using a single registration strategy:
**rigid initialization followed by affine refinement**, with a lightweight retry
mechanism for outlier seeds.

The goal of this evaluation is to verify that the pipeline produces stable,
reproducible calcium–centerline proximity metrics with a transparent
accuracy–runtime trade‑off.

---

## Configuration

- **Registration tool:** SimpleITK  
- **Metric:** Mattes Mutual Information (MMI)  
- **Transform stack:** rigid → affine (no deformable stage)  
- **Multi‑resolution schedule:**
  - shrink factors \[4, 2, 1]  
  - smoothing sigmas \[2.0, 1.0, 0.0]  
- **Vessel zones:** atlas centerlines transformed to NCCT space and dilated to
  ±10 mm to define valid coronary territories.

The evaluation script sweeps multiple random seeds, runs the full registration
pipeline, and records calcium–centerline distances for each seed.

---

## Latest Multi‑Seed Results (Seeds 42–66)

Latest validated run covers seeds **42–66** (25 runs), with metrics from
`experiments/registration_comparison_summary.csv`.[^1]

| Metric | Value |
|---|---:|
| Strategy | `rigid_affine` |
| Mean distance (mean) | 6.8625 mm |
| Mean distance (median) | 6.5412 mm |
| Mean distance (std) | 2.5299 mm |
| Percent within 10mm (mean) | 74.73% |
| Percent within 10mm (median) | 74.31% |
| Percent within 10mm (std) | 13.55% |
| Runtime per scan (mean) | 1.9765 sec |
| Runtime per scan (median) | 1.7801 sec |

These values exceed the >70% proximity target while keeping average runtime per
scan under 2 seconds on the synthetic demo setup.

## How to Reproduce These Results

From the repository root, with `.venv` activated:

```bash
# Windows PowerShell
.\.venv\Scripts\Activate.ps1
python scripts/run_registration_comparison.py --seed-start 42 --seed-end 66

# Linux/macOS
source .venv/bin/activate
python scripts/run_registration_comparison.py --seed-start 42 --seed-end 66
```

This will regenerate:

- `experiments/registration_comparison.csv`  
  (per‑seed metrics)
- `experiments/registration_comparison_summary.csv`  
  (mean / median / std across seeds)
- `docs/images/within_10mm_by_seed.png`
- `docs/images/mean_distance_by_seed.png`
- `docs/images/runtime_by_seed.png`
